# 怎么选医生

> 结论先行：没有「最好的医生」，只有「对你这个病、这个阶段最匹配的医生」。
> 职称是用来初筛的，不是用来排序的；亚专业匹配比职称高一档更重要。

## 一、为什么「最好」不存在

1. **能力不可观测**：手术量、并发症率、诊断准确率都不公开，患者只能看标签。
2. **标签会失真**：职称评的是论文、课题、外语，不是手术做得好不好。
3. **需求不同**：常见病要熟练与沟通，疑难病要判断与资源，急症要速度。

所以能做的，是用可观测的信号逼近「匹配度」，而不是排一个总榜。

## 二、五步法

### 第一步：把病翻译成亚专业

先定亚专业，再看人。判断方法：症状关键词 + 医院官网的「专病门诊 / 亚专业组」名称。

| 症状/诊断 | 该找的亚专业 | 常见误配 |
| --- | --- | --- |
| 手腕麻、夜间加重 | 手外科 / 腕关节 | 关节外科 |
| 突发突止的心慌 | 电生理 | 冠心病门诊 |
| 手抖、动作变慢 | 运动障碍 | 脑血管病门诊 |
| 膝盖上下楼痛、交锁 | 运动医学 / 关节 | 脊柱外科 |
| 腰腿痛伴下肢麻木 | 脊柱外科 | 疼痛科（可先保守） |

### 第二步：看四个「临床角色」信号

| 信号 | 怎么看 | 含义 |
| --- | --- | --- |
| 专病门诊 | 挂号系统里的门诊名称 | 长期只处理这一类病 |
| 手术/介入量 | 简介里的「年手术量」「数千例」 | 熟练度最直接的代理指标 |
| 团队职务 | 科室副主任、亚专业组长 | 既在一线，又能调动资源 |
| 指南/质控 | 共识作者、质控中心成员 | 行业内的话语权 |

### 第三步：职称与年龄组合，而不是单看职称

| 场景 | 优先 | 原因 |
| --- | --- | --- |
| 常见病、慢性病 | 35–45 岁的副主任/主任医师 | 一线主力，号好挂，沟通时间足 |
| 疑难、罕见、诊断不明 | 亚专业带头人（多为 50+ 主任医师） | 模式识别与跨学科资源 |
| 常规手术 | 高年资主治—副主任 | 台次多、手熟 |
| 高难度/二次手术 | 亚专业带头人 | 处理并发症与意外的能力 |
| 需要长期随访 | 有固定专病门诊的医生 | 连续性好，调药/程控方便 |

### 第四步：看科研与临床的配比

- 研究方向与亚专业一致 = 加分；跨好几个领域 = 谨慎。
- 临床研究（队列、术式对比、真实世界）比纯基础研究更贴近看病。
- 晋升特别快、简介大半是论文和基金 = 临床时间可能被摊薄。
- 简介里全是「年手术 X 台、擅长 X 术式」的，通常是临床型。

### 第五步：可得性与连续性

再好的医生，挂不上、复诊不了、每次换人，效果都会打折。优先选：出诊频次高、院区固定、能加号、愿意接随访的。
手术类要问一句「术后复查找谁」。

## 三、常见口诀的适用边界

这些说法在知乎等平台流传很广（例：[「认准副主任，不找老医生，不找有行政职务的」靠谱吗](https://www.zhihu.com/question/1966112870988214912)，76 万浏览），背后有合理逻辑，但都有前提。

| 说法 | 合理之处 | 什么时候不成立 |
| --- | --- | --- |
| 认准副主任 | 35–45 岁、在一线、号好挂、兼顾经验与精力 | 疑难重症、复杂手术仍需亚专业带头人 |
| 不找老专家 | 知识更新慢、体力下降、技术可能停留在过去 | 诊断不清的内科病，老专家的模式识别仍难替代 |
| 不找有行政职务的 | 时间被会议和行政切碎 | 科主任往往就是该领域技术权威，可挂其团队 |
| 年轻+论文多要小心 | 评审重科研，存在「临床一般、科研很强」的路径 | 论文方向与亚专业一致、做临床研究的除外 |
| 主治最稳 | 日常看诊主力，常见病熟练 | 复杂病、手术科室要看主刀权限 |
| 论文只看方向 | 长期聚焦一个亚专业说明真在钻研 | 纯基础研究可能离临床很远 |
| 看患者评价 | 反映沟通与体验 | 样本偏差大，差评可能被过滤 |
| 挂特需/国际部 | 问诊时间长、检查快 | 价格高不等于水平高 |
| 首诊挂普通号 | 先做检查再找专家，省时省钱 | 急症、需手术评估的直接找专科 |
| 认准专病门诊 | 长期只做一类病，匹配度高 | 有些「中心」是挂牌，需看坐诊医生本人 |

补充两点常被忽略的：

- **科室之间差别极大**：ICU、外科吃经验，皮肤科、精神科更吃沟通与细致。
- **基层医院**：副主任与主任的实际差距可能更小，不必舍近求远。

## 四、分科室的亚专业地图

| 科室 | 亚专业（挂号时看这些词） | 常见误配 |
| --- | --- | --- |
| 心血管内科 | 冠脉介入、电生理/起搏、结构性心脏病/瓣膜、心衰心肌病、高血压 | 房颤去看「冠心病专家」 |
| 神经内科 | 脑血管病/介入、癫痫、帕金森/运动障碍、神经免疫、认知障碍、头痛眩晕 | 手抖挂成「脑血管」 |
| 骨科 | 脊柱、关节、创伤、手外/显微、运动医学、足踝、骨肿瘤 | 腕管综合征挂关节外科 |
| 普外科 | 肝胆胰、胃肠、甲状腺乳腺、血管、疝 | 把「微创」当亚专业 |
| 泌尿外科 | 肿瘤、结石、前列腺/尿控、男科、肾移植 | 结石挂肿瘤专家 |
| 肿瘤科 | 按瘤种分（肺、乳腺、消化、妇科），放疗 vs 内科 | 只看「肿瘤科」三个字 |
| 妇产科 | 妇科肿瘤、普通妇科、产科、生殖医学 | 不孕挂普通妇科 |
| 儿科 | 按系统分（呼吸、消化、神经、血液、新生儿） | 忽略儿童与成人用药差异 |
| 眼科 | 眼底、白内障、青光眼、屈光、斜弱视 | 近视手术挂眼底专家 |
| 耳鼻喉 | 耳科、鼻科、咽喉、头颈肿瘤 | 耳鸣挂咽喉 |

## 五、红旗信号

比职称更值得警惕的，是下面这些行为。出现任意两条，建议换人。

1. 不看既往检查就下结论，或全盘否定之前的治疗。
2. 承诺治愈率、「包治」「绝对安全」「不用复查」。
3. 强烈推荐与病情无关的自费项目或自费药。
4. 拒绝解释为什么做某项检查或手术，不给病历和手术记录。
5. 靠贬低同行来建立信任。
6. 网红式科普，内容与带货、导流绑定。
7. 问「一年做多少例」时含糊其辞或转移话题。
8. 门诊三分钟打发，不给你提问的机会。

## 六、首诊与复诊

**带什么**：既往病历、出院小结、手术记录；近期检查报告（影像带原始片子或光盘）；正在吃的药（含剂量）；症状时间线。

**问什么**：

- 我的情况属于您常做的哪一类？一年大概多少例？
- 有哪些方案？各自的成功率和主要风险是什么？
- 如果先保守治疗，方案是什么、多久复诊、什么情况需要升级？
- 术后/用药后，出现什么情况要马上回来？

**什么时候换医生**：

- 诊断方向明显不对，或两个月内治疗方案没有任何调整；
- 关键问题反复得不到正面回答；
- 出现红旗信号；
- 病情超出当前医院/科室的能力边界（这时是升级机构，不是换同层级的医生）。

## 七、决策清单

- [ ] 我知道自己的病属于哪个亚专业
- [ ] 我选的医生，简介里的「擅长」与我的病一致
- [ ] 他/她有专病门诊或明确的亚专业组
- [ ] 简介里有可验证的手术量/介入量描述
- [ ] 职称、年龄、临床角色三者不矛盾
- [ ] 科研方向与临床方向一致，不是纯基础研究
- [ ] 我能在合理时间内挂到号并完成复诊
- [ ] 面诊时没有被红旗信号击中

八项里有两项以上为「否」，就再找一位候选对比。

## 八、局限

- 所有判断基于公开信息的「自述」，不是客观排名，不能替代面诊。
- 职称、排班、简介随时变化，引用请注明日期。
- 个体差异很大，同一医生在不同患者身上的体验可能完全不同。
- 本文不构成诊疗建议；具体方案以接诊医生意见为准。

> 各渠道怎么取、可信度如何、有哪些坑，见 [医生信息源手册](doctor-info-sources.md)。
